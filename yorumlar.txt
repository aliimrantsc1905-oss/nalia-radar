# BÜRO YORUMLARI
#
# Radarda "Büro notu" olarak en üstte görünecek kayıtları buraya yazın.
# Her kayıt üç tire (---) ile başlar. "yorum:" satırından sonra
# istediğiniz kadar satır yazabilirsiniz; bir sonraki --- satırına kadar
# hepsi yorumun parçası sayılır.
#
# Alanlar:
#   tarih  : YYYY-AA-GG biçiminde (zorunlu)
#   baslik : Kararın veya düzenlemenin kısa adı (zorunlu)
#   kaynak : Karara / düzenlemeye bağlantı (isteğe bağlı)
#   alan   : Ceza, Aile, İş, İdare, İcra, Ticaret, Gayrimenkul, Borçlar,
#            Vergi, Tüketici, Bilişim, Anayasa (virgülle birden fazla yazılabilir)
#   yazar  : Notu yazan avukat (isteğe bağlı)
#   yorum  : Büronun kısa değerlendirmesi (zorunlu)
#
# "#" ile başlayan satırlar dikkate alınmaz. Aşağıdaki örneği silip
# kendi notlarınızı ekleyebilirsiniz.
